# Derr1ck 阅读器 · 产品设计文档（MVP 版）

> 版本：v1.0 MVP　　日期：2026-09-13　　状态：待开发
> 本文档梳理整体方向与主要功能，不细化到交互原型与接口设计。

---

## 一、产品定位

**一句话定义**：一个纯本地的 Web 电子书阅读器，打开浏览器就能读自己导入的书。

- **目标用户**：个人自用起步，兼顾有本地电子书阅读需求的轻度用户
- **核心价值**：无需注册、无需上传、隐私安全；导入即读，下次接着读
- **平台**：Web 网页版（桌面浏览器优先，移动端浏览器自适应即可，不做专门优化）

## 二、设计原则

1. **本地优先**：所有数据（书籍、进度）只存在浏览器 IndexedDB，不上传任何服务器
2. **闭环最小化**：只做「导入 → 书库 → 阅读 → 续读」一条链路
3. **克制**：任何不在本文档范围内的功能，一律进入第六章"可推迟功能列表"

## 三、技术方案（概要）

| 部分 | 选型 | 说明 |
|------|------|------|
| 前端框架 | React + Vite | 快速迭代 |
| EPUB 解析 | epub.js | 章节渲染、目录提取 |
| TXT 解析 | 自研 | 纯文本按规则切章 + 编码检测 |
| 本地存储 | IndexedDB（Dexie.js） | 书籍文件 + 阅读进度 |
| 部署 | GitHub Pages | 免费静态托管 |

## 四、功能设计

### 4.1 书籍导入

- 支持格式：**EPUB**、**TXT**
- 交互：书库页「导入书籍」按钮 + 拖拽文件到页面
- 解析元数据：书名（文件名兜底）、封面（EPUB 自带则显示，无封面用占位图）、目录
- **编码限制（第一版）**：TXT **仅支持 UTF-8 编码**；检测到非 UTF-8 时给出明确提示「请先将文件转为 UTF-8 编码」，不支持自动转码
- 同名书籍去重提示（可选覆盖或跳过）

### 4.2 书库主页

- 封面网格展示，卡片显示：封面、书名、作者（若有）、阅读进度百分比
- 操作：打开阅读、删除（需二次确认）
- 空状态引导：提示用户导入第一本书

### 4.3 阅读界面

- **阅读方式：仅纵向滚动**（第一版不分页、不做横向翻页）
- 顶部悬浮工具栏（阅读时自动隐藏）：
  - 返回书库
  - 目录侧栏（章节跳转）
- 底部/设置面板：
  - 字号调节（3~5 档）
  - 行距调节
  - 主题：浅色 / 深色 / 护眼（米黄）
- 进度感知：滚动时实时计算并保存阅读位置（按百分比 + 章节内锚点）

### 4.4 阅读进度记忆

- 每本书独立保存：当前章节 + 章节内位置（像素偏移或百分比）
- 打开书籍时自动跳转到上次位置
- 进度变化防抖保存（如停止滚动 2 秒后写入）

### 4.5 大文件加载提示

- 阈值：文件大小 **> 20MB** 判定为大文件
- 处理策略：
  1. 导入时提示「文件较大（xx MB），解析可能需要一些时间」并显示加载动画
  2. 解析时间超长（>10s）允许取消
  3. 阅读 TXT 大文件时**按章节惰性加载**（只渲染当前章节附近内容），避免一次性渲染卡死页面
- 通用兜底：所有解析操作均有 loading 状态和失败提示（文件损坏 / 格式不支持）

## 五、非功能要求

- **隐私**：零网络请求依赖（除首次加载应用本体），不接任何统计/分析 SDK
- **性能**：常规书籍（<20MB）打开阅读界面 <2s
- **兼容**：Chrome / Edge 最新两个大版本
- **数据安全**：删除书籍时明确提示「进度将一并删除，不可恢复」

## 六、可推迟功能列表（Out of Scope for MVP）

| 功能 | 推迟原因 | 预期版本 |
|------|----------|----------|
| PDF 格式支持 | 渲染复杂，EPUB/TXT 已覆盖主要场景 | v2 |
| 云同步 / 多设备 | 需账号体系 + 后端，工作量翻倍 | v2 |
| 分页/翻页阅读模式 | 滚动模式够用后再做 | v2 |
| TXT 非 UTF-8 编码自动识别与转码 | MVP 手动转码成本可接受 | v2 |
| 批注、划线、笔记 | 阅读闭环外的增强功能 | v2/v3 |
| 书架分组 / 标签 / 搜索 | 书多了再做 | v2 |
| 在线书源 / 书籍搜索 | 涉及版权与爬虫维护 | 视需求 |
| 听书 / TTS | 独立大功能 | 视需求 |
| 移动端专用适配（手势、排版） | 先保证桌面 Web 体验 | v2 |
| 阅读统计（时长、日历） | 锦上添花 | v3 |

## 七、里程碑建议

| 阶段 | 内容 | 目标 |
|------|------|------|
| M1 骨架 | Vite + React 项目搭建、路由、主题切换 | 可运行的空壳 |
| M2 导入与书库 | EPUB/TXT 导入、IndexedDB 存储、书库网格 | 能看到自己的书 |
| M3 阅读器 | 滚动阅读、目录跳转、字号/主题设置 | 能读下去 |
| M4 进度与打磨 | 进度记忆、大文件提示、异常处理、部署上线 | MVP 发布 |
